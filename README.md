# 红图去水印 - 小红书图片/视频无水印解析工具

## 项目介绍
这是一个功能强大的小红书去水印在线工具。支持：
1. **高清无水印图片解析**：完美支持小红书最新 `sns-img` 域名，批量提取无水印原图，支持打包 ZIP 下载。
2. **高清无水印视频解析**：前端直连小红书 CDN 极速下载，彻底绕过代理服务器超时限制，且内置 Referer 伪装防盗链机制，无缝播放和下载。
3. **笔记文案一键复制**：精准提取笔记标题与正文。
4. **商业化防白嫖系统**：内置一机一码卡密授权机制（基于 Vercel KV Redis），强绑定设备指纹，彻底防止卡密二次倒卖。
5. **智能链接提取**：用户粘贴整段图文分享，前端自动剥离杂字，提取纯净链接。

## 技术栈
- **框架**: Next.js 14+ (App Router)
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **部署/数据库**: Vercel + Vercel KV (Redis)

## 本地运行指南
1. 克隆代码后，安装依赖：
   ```bash
   npm install
   ```
2. 启动开发服务器：
   ```bash
   npm run dev
   ```
3. 打开浏览器访问 `http://localhost:3000`。

> **测试卡密**：
> 在本地环境下，系统会自动降级使用 `data/licenses.json` 文件作为数据库。
> 您可以使用以下内置测试卡密体验一机一码授权流程：
> - `VIP-MONTH-8888` （有效包月）
> - `VIP-YEAR-9999` （有效包年）
> - `VIP-TEST-0000` （已过期拦截测试）

## 生产环境部署 (Vercel)

本项目极度推荐使用 [Vercel](https://vercel.com/) 进行零配置免费部署，并无缝接入其 KV 云数据库以实现真正的公网防白嫖。

### 部署步骤
1. 将本项目代码推送到您的 **GitHub** 仓库。
2. 登录 Vercel，点击 **Add New... -> Project**，导入您刚刚推送的 GitHub 仓库。
3. 点击 **Deploy**，等待部署完成。

### 激活云端数据库 (防倒卖必做)
为了让一机一码系统在公网上生效，您需要激活云端数据库：
1. 在 Vercel 项目面板，点击顶部的 **Storage** 选项卡。
2. 点击 **Create Database**，选择 **KV (Redis)** 并创建一个免费数据库。
3. 创建完成后，进入数据库的详情页，确保它已经连接（Connected）到您的项目。Vercel 会自动将 `KV_REST_API_URL` 和 `KV_REST_API_TOKEN` 环境变量注入到您的项目中。
4. **重新部署一次**（在 Deployments 页面点击最新的部署右侧的三个点，选择 Redeploy），您的系统就会瞬间从本地 JSON 切换为云端 Redis。

### 商业化发卡指南
部署完成后，当有客户向您购买卡密时，您只需在 Vercel KV 的管理后台的 CLI 中执行以下命令即可发卡：

```redis
# 生成一个一年有效期的卡密 (过期时间戳 1808000000000)
SET license:VIP-NEW-2026 '{"deviceId":null,"expiresAt":1808000000000,"note":"卖给张三的年卡"}'
```
（注：`deviceId` 设为 `null` 代表这是一个新卡密，当客户第一次使用时，系统会自动将他的设备指纹填入此处死死绑定。）
